# Evidence at Scale

[Review map](README.md) · [Main survey](../../README.md#paradigms)

Supporting methods for frame selection, token compression, temporal grounding, and audio-visual representations. These improve the evidence interface; efficiency gains alone do not establish a new reasoning mechanism. Report preprocessing, retrieval, and encoder costs as well as retained tokens.
