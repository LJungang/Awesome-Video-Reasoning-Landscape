# Always-On Intelligence

[Review map](README.md) · [Main survey](../../README.md#paradigms)

Observed-prefix reasoning, memory updates, response timing, and proactive interaction. Report query-arrival rules, access to discarded frames, total retained history, and end-to-end latency. Streaming video generation belongs under world models rather than this understanding-oriented branch.
